# avx512.sh

The cards' side of the stream is the sibling repository
[Intel-Phi-AVX512](https://github.com/Lasimeri/Intel-Phi-AVX512): its
`scripts/phi-ggml.sh` starts the card workers and names the backend
`libggml_phi.so` to ggml through `GGML_BACKEND_PATH`, which llama.cpp
honours unchanged. `scripts/phi-stream.sh` sources this file to find it.
In order, the first that is set or present is used:

1. `PHI_AVX512_ROOT`.
2. A checkout next to this one, named `Intel-Phi-AVX512` (a `git clone`)
   or `Intel Phi AVX-512`, holding `scripts/phi-ggml.sh`.
3. The same two names in `$HOME`.

Not finding it is not an error: without the cards the host blocks'
experts are multiplied by llama.cpp's own CPU backend and the stream
runs on the GPU and the host (slower at generation: the cards take two
thirds of those multiplies when present). A `PHI_AVX512_ROOT` that is
set but holds no `scripts/phi-ggml.sh` stops the script (exit 1). The
same order finds every sibling in this family of repositories; nothing
of a sibling is copied here.
