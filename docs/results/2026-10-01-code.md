# 2026-10-01: does it write code that works

The user's requirement: the stream must write coherent computer code,
so that it is a usable system and not only an experiment. This record is
the measurement that requirement is held to, and its first numbers.

Host, model and split as the other records of the day (Qwen3.8-35B-A3B
Q6_K over the 3090 Ti, both cards and host memory; llama.cpp f5b9bd3
unchanged). Tasks: MultiPL-E's HumanEval in Rust, 156 tasks, fetched
pinned (`scripts/fetch-code-eval.md`). Every program compiled with
`rustc 1.98.1` and run in the sandbox of `src/code.md` (no network, a
user namespace, limits on memory, CPU, files and wall time). Logs and
every program under `~/.cache/phi-stream/code/` and
`~/.cache/phi-asm-test/stream/code/`.

Evaluation only: MultiPL-E's licence (BSD 3-Clause with a machine
learning restriction) forbids its contents as training data in its
clause 4; nothing these runs produce goes into a fine-tune.

## The anchor: the benchmark's own protocol

`scripts/phi-stream.sh code anchor` (`anchor-full.out`): the raw prompt,
no chat template, no persona, greedy, completed until the stop sequence
`\n}`, at most 512 tokens.

| tasks | pass | test failure | compile error | timeout | no code | tokens a task | seconds a task |
| --- | --- | --- | --- | --- | --- | --- | --- |
| 156 | **116 (74.4 %)** | 25 | 15 | 0 | 0 | 90 | 3.2 |

The split with the cards writes correct Rust: three tasks in four by the
benchmark's protocol, greedy, the first sample (pass@1). The compile
errors include the protocol's own limits: the stop sequence ends the
completion at the function's closing brace, so a helper written after it
is cut off (prime_fib calls `is_prime`, match_parens `is_balanced`), and
string_to_md5 needs a crate that no task has.

## The stream's own way

`code stream` is the engine's task mode: the chat frame with thinking,
greedy, no penalty, a thinking budget of 2048, and the extraction rule of
`src/code.md`. It ran with a neutral base on the frozen binary
`phi-stream.frozen2` (`stream-neutral.out`; run directory
`~/.cache/phi-stream/code/stream-neutral-1790881082`). The run was
stopped at the user's hand after 90 of the 156 tasks, and the
`CLAUDE.md`-based run that was to follow never started. These are the
first 90, in the anchor's order, against the anchor on the same 90:

| first 90 tasks | pass | test failure | compile error | no code | thinking tokens a task | answer tokens | seconds a task |
| --- | --- | --- | --- | --- | --- | --- | --- |
| anchor (the benchmark's protocol) | 77 (85.6 %) | 9 | 4 | 0 | | 84 | 3.1 |
| the stream, neutral base | **82 (91.1 %)** | 6 | 1 | 1 | 270 | 138 | 11.8 |

Thinking first and answering whole functions passes five more of these
90 than completing the raw prompt, at about four times the time a task.
- **The no code** is fizz_buzz: its thinking ran to the budget (2048
  tokens) and the answer after `</think>` held no block defining the
  function.
- **The compile error** is fruit_distribution.
- **The six test failures**: make_palindrome, all_prefixes,
  triples_sum_to_zero, largest_prime_factor, any_int and encode. Of
  these, make_palindrome, largest_prime_factor, any_int and encode also
  fail in the anchor.
- **The anchor's own protocol failures** pass here: prime_fib (its
  helper cut off by the stop sequence) and the other compile errors.

**Not repeatable as run.** Until the commit after 1fe929d, a task's
opening carried the wall clock to the microsecond, as the stream's does,
so the same greedy task did not see the same prompt twice. Later the
first 34 tasks ran again on the reflection record's mind arm, a binary
that changes no logits. 20 of their 34 answers differed from this run's.
The 82 of 90 is therefore one sample of a process that varies from run
to run, and the difference of five against the anchor is within a
variance this run cannot show. A task's text now carries no time, and
the reflection record checks that a task repeats byte for byte before
comparing anything.

The remaining 66 tasks, and the `CLAUDE.md` base, are not measured yet.
The partial number is labelled as such wherever it is used.
